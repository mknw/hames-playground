Two output-cleanup fixes.

- **`repairJson` / `repairJsonTracked`** (`@hames-ai/harness-patterns`) no longer fold a malformed multi-key object into its first key (#408). The last-resort handler for a single key whose bare value holds commas checked only that the input began with one key, so `{a: [x,,y], b: 1}` came back as `{ a: "[x,,y], b: 1" }`, tagged `lenient-tokens`. It now declines whenever the would-be value holds something shaped like another member (`, b:`, `"b":`, `'b':`), and the call **throws**: `actorCritic` retries it; `simpleLoop` ends the loop with a recoverable `Invalid tool_args JSON` error. **Behaviour change for callers**: inputs that used to return one wrong key now throw. The decline is deliberately conservative, so some inputs the old handler got right now throw too: a Cypher label predicate or label write after a comma (`RETURN a, b:Person`, `SET a:Customer, b:Vendor`, `REMOVE …`), and a quoted word followed by a colon (Python's `if x == "y":`, once the same code also holds an ambiguous `print("a", b)`). A value that is one cleanly quoted string is exempt, so `{query: "RETURN n, n:Person"}` still repairs.
- **`sanitizeTitle`** (`@hames-ai/agents`) takes the first line of the model's reply before it strips surrounding quotes and trailing punctuation (#409), so `"Graph Styling Tips"` followed by a second line no longer keeps its closing quote.
