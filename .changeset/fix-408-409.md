Two output-cleanup fixes.

- **`repairJson` / `repairJsonTracked`** (`@hames-ai/harness-patterns`) no longer fold a malformed multi-key object into its first key (#408). The last-resort handler for a single key whose bare value holds commas checked only that the input began with one key, so `{a: [x,,y], b: 1}` came back as `{ a: "[x,,y], b: 1" }`, tagged `lenient-tokens`. It now declines whenever the would-be value holds something shaped like another member (`, b:`, `"b":`, `'b':`), and the call **throws**, which the loop patterns already turn into an `Invalid tool_args JSON` turn the model retries. **Behaviour change for callers**: inputs that used to return one wrong key now throw. The decline is deliberately conservative: a Cypher label predicate after a comma (`RETURN a, b:Person`) reads as a member and also throws. A value that is one cleanly quoted string is exempt, so `{query: "RETURN n, n:Person"}` still repairs.
- **`sanitizeTitle`** (`@hames-ai/agents`) takes the first line of the model's reply before it strips surrounding quotes and trailing punctuation (#409), so `"Graph Styling Tips"` followed by a second line no longer keeps its closing quote.
